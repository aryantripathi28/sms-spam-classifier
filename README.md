# SMS Spam Classifier

An end-to-end **Machine Learning–based SMS Spam Classifier** that uses Natural Language Processing (NLP) techniques to classify messages as **Spam** or **Not Spam**.

This project demonstrates the complete ML workflow — from text preprocessing and feature extraction to model training and inference.

---

## Project Overview

Spam detection is a classic NLP problem where the goal is to automatically identify unwanted or harmful messages.  
In this project, SMS messages are cleaned, vectorized using TF-IDF, and classified using a supervised learning model.

---

## Tech Stack

- Python  
- Pandas, NumPy  
- Scikit-learn  
- NLTK  
- Streamlit (for UI, if applicable)  

---

## Workflow

1. **Data Cleaning**
   - Lowercasing text
   - Removing punctuation
   - Removing stopwords
   - Stemming

2. **Feature Engineering**
   - TF-IDF Vectorization

3. **Model Training**
   - Supervised ML algorithm trained on labeled SMS data

4. **Prediction**
   - Classifies new messages as:
     - `Spam`
     - `Not Spam`
